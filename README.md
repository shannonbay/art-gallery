# Shannon Bay — Art Gallery

Drawings and paintings by Shannon Bay.

**View the gallery:** https://shannonbay.github.io/art-gallery/

## Adding a piece

1. Put a large copy in `images/full/` and a copy about 720px on its longest side in `images/thumb/`, using the same filename.
2. Copy a `<figure class="work">` block in `index.html`, then update the image paths, size, description, title and medium.
3. Commit and push to `main`. GitHub Pages republishes the site automatically.
